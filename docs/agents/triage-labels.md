# Triage Labels

各工程 skill 用五个规范 triage 角色表述，本文件把它们映射到本仓库实际使用的标签字符串。

| skill 中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

当 skill 提到某个角色（例如「打上 AFK-ready triage 标签」）时，使用表中对应的标签字符串。

如需变更词汇，直接编辑「本仓库标签」一列。
